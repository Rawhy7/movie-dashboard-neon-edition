# Movie Success Predictor – Neon Edition

A redesigned version of the [Movie Success Predictor](https://github.com/Rawhy7/movie-dashboard) with a bold, neon-style interface. It uses the same idea: enter a movie's budget and expected ratings, and the app estimates its revenue, profit and chance of success using models trained on a dataset of movies.

## Built with

Python · Pandas · NumPy · scikit-learn · Streamlit

## Run it locally

```bash
git clone https://github.com/Rawhy7/movie-dashboard-neon-edition.git
cd movie-dashboard-neon-edition
pip install -r requirements.txt
streamlit run funky_dashboard.py
```
